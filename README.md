# Introduction to Programming

## Python modules and text files tutorial

**[Download tutorial ZIP](https://github.com/abhayshastry/Intro_to_programming/raw/refs/heads/main/student_tutorial.zip)**

[Browse the individual files and full instructions](student_tutorial/examples/README.md)

1. Download the ZIP. On Windows, right-click it and choose **Extract All**.
2. In VS Code, choose **File > Open Folder** and open the extracted **examples** folder.
3. Select the Python 3 interpreter you use for class with **Python: Select Interpreter**.
4. Choose **Terminal > New Terminal** and run:

   ```text
   python compare_scores.py
   ```

   Expect `Class A: 78.0` and `Class B: 80.0`.

All files and sample data are included; there are no Python packages to install.
If your Windows Python command is `py`, use `py` instead of `python`.

Study the completed examples, then fill in `modules_exercise.py` and
`scores_exercise.py`. Check your work in the same terminal:

```text
python self_check.py modules
python self_check.py files
```

The exercises start unfinished, so initial failures are expected. Each failed
check includes a hint. The targets after completion are **5 PASS** for modules
and **12 PASS** for files. Read the [tutorial guide](student_tutorial/examples/README.md)
for the slide-to-exercise map and the remaining examples.
